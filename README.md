# Тесты по академическому письму · ТГТУ

Vite-проект без фреймворков: `index.html` + `src/style.css` + `src/main.js`.
Каждая презентация — отдельный JSON-файл в `src/tests/`. Главная страница и маршруты строятся автоматически.

## Запуск
```bash
npm install
npm run dev       # разработка, http://localhost:5173
npm run build     # сборка в dist/
```

## Как добавить новую презентацию
1. Скопируйте любой файл из `src/tests/` и переименуйте латиницей, например `src/tests/novaya-tema.json`.
2. Поправьте поля: `slug` (адрес теста, совпадает с именем файла), `order` (номер темы, по нему сортируются карточки), `title`, `subtitle`, `questions`.
3. Положите PDF в `public/slides/novaya-tema.pdf` (если файла нет — удалите поле `pdf`, и кнопка «Презентация» не появится).
4. `git add . && git commit -m "новая тема" && git push` — Netlify соберёт сайт сам.

Формат вопроса: `{ "q": "текст", "o": ["а","б","в","г"], "a": 1, "e": "пояснение", "s": 3 }`
(`a` — номер правильного варианта с нуля: 0 — первый, `s` — номер слайда для повторения).
Варианты перемешиваются при каждом прохождении.

## Netlify
Репозиторий подключается как есть: `netlify.toml` уже содержит команду сборки (`npm run build`), папку `dist` и перенаправление для адресов вида `/slug`.
Ссылки из PDF (`/rubrikatsiya-teksta`, `/funktsionalnye-stili-rechi`) продолжают работать.

## Оформление
Цвета и скругления — переменные в начале `src/style.css` (`--brand`, `--brand2`, `--gold`). Логотип — блок `.mark` в `index.html`: замените текст на `<img src="/logo.svg">`, положив файл в `public/`.
